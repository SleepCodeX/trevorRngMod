# Trevor Roll

Small hunts. Big moments. Your client-side Trevor companion for **Hypixel SkyBlock**.

**[Download 1.9.1](https://github.com/SleepCodeX/trevorRngMod/releases/latest)** · **Minecraft 26.2 · Fabric · Java 25**

![Trevor's module cards, quick tabs and search](docs/media/1.9.1/settings-modules.png)

Open **`/trevormod settings`**.

## Extreme Elusive

![Beth notices you, then ELUSIVE MOB FOUND and the dragon](docs/media/1.9.1/elusive-journey.webp)

Select **Jackpots → Extreme**, then enable **Extreme 3D roll**. The intro plays **only for Elusive**, with its own duration control. The roar follows the dragon transition.

## Menu & keys

![Shortcut, fades and advanced graphics preferences](docs/media/1.9.1/menu-keys.webp)

The shortcut starts **unbound**. Set it here or in **Minecraft Controls → Trevor Roll**. During capture, **Escape** cancels; **Delete / Backspace** clears.

## Install

1. Use **Minecraft 26.2**, **Java 25**, **Fabric Loader 0.19.5+** and **Fabric API for 26.2**.
2. Put [trevor-roll-1.9.1.jar](https://github.com/SleepCodeX/trevorRngMod/releases/download/1.9.1/trevor-roll-1.9.1.jar) in `mods`. Remove older Trevor Roll JARs.
3. Join Hypixel SkyBlock, talk to Trevor, and keep your crest in the hotbar.
