# Trevor Roll 1.6.0 media

These files are public documentation assets for the README and release page.

- PNGs are unmodified Minecraft 26.2 / Fabric Loader 0.19.5 screenshots from the production-client validation of the 1.6.0 runtime. Hunts and crest states use the test world's preview commands, not a live Hypixel session.
- `elusive-styles.gif` is the silent four-style comparison generated by `ElusiveRewardTest` using `ElusiveRewardPainter` and the same HD coin atlases as the game. It uses an approximate system font and is not a screen recording.
- Source evidence: [validated runtime and screenshots](https://github.com/SleepCodeX/trevorRngMod/actions/runs/40789218740). Later commits before release changed setup documentation only; [main release validation](https://github.com/SleepCodeX/trevorRngMod/actions/runs/40794431062) also passed.

The crest screenshots intentionally show `Pelts/hour: --` because they are preview states, not a measured session. No pelt rate has been added to the images.

Keep this versioned directory available so existing release-page image links continue to work.
