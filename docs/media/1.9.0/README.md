# Trevor Roll 1.9.0 media

Source: `231773910dfa0ae1c80625b12c05c5aeaad2f505`. Native Minecraft 26.2 / Fabric Loader 0.19.5 captures from
[production-client run 41407571274](https://github.com/SleepCodeX/trevorRngMod/actions/runs/41407571274).
The evidence artifact contains the original screenshots and logs.

PNGs are unchanged game screenshots. Animated WebP preserves the captured
game frames without colour quantization. Only the two documented HUD crops remove surrounding space;
no text, counts, objects or model details were added to the captures.

`solid-models.webp` samples native model poses every 100 ms for six seconds using
the production rotation clock. `elusive-journey.webp` samples the native scene every
100 ms across its 8.5-second timeline, then pauses on the final frame for one extra
second. These are deterministic game-rendered pose sequences, not continuous
screen recordings or performance measurements. `modules-advanced.webp` preserves
the capture spacing of the live dashboard. Other feature animations compare settings or
HUD states; their pauses are for reading.
